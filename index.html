Características del Sistema

Una solución completa para el mantenimiento industrial

📡

Conexión OPC-UA

Integración directa con PLCs industriales para captura de datos en tiempo real de sensores de temperatura, vibración y más.

🤖

Agente IA RAG

Sistema de diagnóstico inteligente que utiliza Retrieval-Augmented Generation para consultar manuales técnicos y histórico de reparaciones.

🚨

Detección de Anomalías

Monitoreo continuo con alertas automáticas cuando los valores superan los umbrales definidos.

💬

Asistencia Conversacional

Chat interactivo con el agente IA para guiar a los técnicos paso a paso en las reparaciones.

📊

Dashboard Visual

Interfaz web intuitiva con métricas, gráficos de tendencias y visualización en tiempo real.

📋

Historial Completo

Registro detallado de todas las anomalías, diagnósticos y acciones para análisis y mejora continua.

Tecnologías Utilizadas

Stack moderno para soluciones modernas

🐍 Python 📊 Streamlit 🔌 OPC-UA 🧠 LangChain 💾 ChromaDB 📚 HuggingFace 📈 Pandas 🔗 asyncua 🌐 REST API

¿Por qué este proyecto?

En la industria moderna, el tiempo de inactividad (downtime) representa pérdidas millonarias. Este sistema busca reducir drásticamente ese tiempo mediante:

Diagnóstico Inteligente: El agente IA analiza los datos en tiempo real y propone soluciones basadas en manuales técnicos y experiencias previas.

Asistencia 24/7: Un "experto virtual" disponible siempre para guiar a los técnicos.
